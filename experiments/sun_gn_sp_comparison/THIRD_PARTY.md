The [DC/ACE source manifest](source/method-adapters/vendor-manifest.json) records original file hashes and source URLs; it is provenance metadata, not the referenced contents. Native DC/ACE cores are selected by a hash-checking AST loader, while the task adapters change their surrounding episode interface. These are task-adapted core pilots, not full upstream CLI or paper-result reproduction. ACE's inspected default merge primarily implements ADD; optional analysis/refinement machinery is not silently credited as having run.

The SP episode adapter is omitted from this public source subset because it contains an upstream refusal-prompt literal and a private qualification-evidence binding. Its public protocol, method description and pinned upstream links disclose the relevant choices without copying that material or weakening the experiment's original gate. No access credentials, model weights, private task data or external vendor tree is included.
